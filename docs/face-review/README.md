# Face distortion review

Open the [review task](./) in a browser. Enter a reviewer ID, then use the buttons or Y / N / U keys to rate each candidate relative to its paired reference. Ratings save in that browser. At the end, click **Download ratings CSV** and send that CSV back to the study owner. No account is needed.

For offline use, download and extract [`reviewer_html_bundle.zip`](./reviewer_html_bundle.zip), then open `review.html` with the `images/` folder beside it. Or use [`review.pdf`](./review.pdf) to print the cases and mark the boxes.

Please do not inspect or search for the hidden experimental conditions while rating. Choose **Unsure** if the face is obscured or the judgment is ambiguous.
