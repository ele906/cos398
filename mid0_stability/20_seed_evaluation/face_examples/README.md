# Generated image examples around landmark detection misses

These contact sheets use actual saved 20-seed mid.0 images. Each sheet shows the α=1 reference, the closest sampled multiplier before the first miss when available, a missed-detection image, and the next sampled multiplier when available. Failed cases were selected by feature, demographic prompt group, seed, and intervention direction. This is illustrative sampling, not an unbiased human-quality evaluation.

There are 877 missed detections among 69600 generated image conditions. This endpoint is MediaPipe landmark detection; a miss does not establish facial distortion, and a detected face is not proof of facial quality.

Contact sheets: 143. Full failure counts are in [failure_counts.csv](failure_counts.csv); included image paths and detector labels are in [examples.csv](examples.csv).
